# Smart Library Management System

## Overview

A Java-based Library Management System developed using Object-Oriented Programming principles.

This project allows users to borrow and return books while tracking loans and validating business rules.

## Features

- Book Management
- User Management
- Loan Tracking
- Borrow Books
- Return Books
- Custom Exception Handling
- Unit Testing with JUnit 5

## Technologies

- Java
- Maven
- JUnit 5
- Git
- GitHub

## Project Structure

Models
- Book
- User
- Loan
- Library

Services
- LibraryService

Exceptions
- BookNotAvailableException
- BorrowLimitExceededException

Tests
- LibraryServiceTest

## How to Run

1. Clone the repository
2. Open in Eclipse
3. Run LibraryApplication.java
4. Run LibraryServiceTest.java as JUnit Test
